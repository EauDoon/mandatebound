Module directory

This directory covers the nine modules in the map. Source links open their current files on GitHub.

Command line Entry point

Reads one strict input document, dispatches a local command, and returns its documented exit code.

Uses Review queue, Case report, CasePack, Engine adapter. Read src/cli.ts

Review queue Review

Orders bounded CasePack assessments for triage, evidence collection and comparison.

Uses Case report. Read src/operator.ts

Case report Review

Turns a verification result into metadata for human review. Keeps eligibility, upstream validity and source truth separate.

Uses CasePack. Read src/report.ts

CasePack Evidence

Exposes the CasePack sealer and verifier. The verifier checks declared coverage, caller-owned anchors, source evidence and the nested native bundle.

No further modules shown in this excerpt. Read src/casepack.ts

Engine adapter Entry point

The CLI uses the default local platform engine to load verification and evaluation functions. This path requires no running HTTP server.

Uses Decision engine, Closed bundle. Read src/api.ts

Decision engine Policy

Derives typed facts from the supplied evidence and records a bounded policy disposition at the explicit assessment time.

Uses Closed bundle, Pinned trust, Rulebook. Read src/engine.ts

Closed bundle Evidence

Checks the manifest, content digests and bundle root for the declared evidence.

No further modules shown in this excerpt. Read src/bundle.ts

Pinned trust Evidence

Checks the pinned trust snapshot and resolves keys against roles, purposes, scopes and proof time.

No further modules shown in this excerpt. Read src/trust.ts

Rulebook Policy

Evaluates the bounded rule language against typed facts. Legal effect remains undetermined.

No further modules shown in this excerpt. Read src/policy.ts
